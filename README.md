# Nazrul Studio | Precision in Design & Production

Repository: [https://github.com/nazruluxd/nazrulstudio](https://github.com/nazruluxd/nazrulstudio)  
Live Domain: [https://nazrulstudio.uk](https://nazrulstudio.uk)

Portfolio, E-Commerce Shop, and CMS platform for **Nazrul Studio**, specializing in high-end structural packaging, branding identity systems, 3D product visualizations, and digital interfaces.

## 🚀 Built With
- **React 18** + **TypeScript**
- **Vite**
- **Tailwind CSS**
- **Firebase Auth & Cloud Firestore** (`nazrulstudio`)
- **GSAP & ScrollTrigger** (for layered stack project showcase)
- **Lucide React** & **FontAwesome**

## ✨ Features
- **Hero & Precision Branding**: Neon glowing avatar, status indicator, dynamic highlights, and direct social links.
- **Section Visibility Management**: Fully customizable toggles for every section.
- **Trusted by Brands**: Grid showcasing brand collaborations (Pepsi, Emirates, Etihad, Emaar, etc.).
- **Technical Arsenal**: Primary skill bars with percentage indicators + categorized tech stack pills.
- **Design Approach**: 5-step strategic work process (Discovery, Strategy, Design, Refinement, Delivery).
- **Comparison Matrix**: Strategic breakdown comparing Nazrul Studio vs. In-House Teams vs. Typical Freelancers.
- **Layered Project Showcase**: GSAP ScrollTrigger-driven stacking card showcase.
- **Selected Works (Portfolio)**: Filterable works grid with hover transitions and quick links.
- **Client Testimonials & Shop Reviews**: Real-time Firestore-synced verified customer reviews with 5-star rating presentation.
- **Protected Admin CMS Dashboard**: Secured exclusively via **Firebase Google Sign-In** (`nazrulcxd@gmail.com`) with Firestore security rules (`isAdmin()`).
